# TaskForce-

Keeps track of schedule and things to do and monitory things.

A personal app with three pages: a daily checklist, money I owe / owed to me, and receipts.
Everything runs in the browser and is saved on the device. Receipt screenshots and pasted
order text are read on the device too (text recognition files are in `tess/`).

## Put it on an iPhone

1. Host this folder on any static web host with HTTPS (for example GitHub Pages:
   repository Settings → Pages → Deploy from branch → `main` / root).
2. Open the site's address in Safari.
3. Tap Share → Add to Home Screen.

It opens full screen like an app and works offline after the first visit.
